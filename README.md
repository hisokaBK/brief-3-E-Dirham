# e-Dirham — Informational Landing Page

A French-language, single-page website exploring the concept of a Moroccan digital dirham and central bank digital currencies (CBDCs).

## Sections

- Introduction to the e-Dirham concept.
- How it works.
- Security and potential benefits.
- Financial inclusion and impact.
- News and launch-related content.
- Newsletter-style form and testimonial-style visuals.

## Technologies

HTML5, CSS3, Font Awesome, images, and video assets.

## Run locally

Open **index.html** in a browser. The page styles are in **style.css**, with media files in the **image/** folder.

## Important distinction

This is an educational/informational front-end concept. It is not an official Bank Al-Maghrib website, a working payment platform, or an implementation of a central-bank-issued digital currency.
